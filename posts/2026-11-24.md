### 腾讯 WePocketModel 1.0：统一生成、检索与决策的端侧模型

**标签：** Multimodal · On-device

**更新：** 腾讯微信 AI 于11月23日开放 2B/4B 两个版本，代码和权重采用 Apache-2.0；共享视觉编码器和语言骨干，支持 OCR、图像描述、VQA、图文向量检索及结构化决策。2B checkpoint 实际约2.23B参数，BF16 权重4.47GB；支持64至2048维 MRL 向量，提供 Transformers 和 GGUF CPU 方案，4B 的 Q4_K_M 语言权重加共享多模态组件约3.19GiB。

## 端侧框架与运行时

### LiteRT v2.4.0：移动 GPU 和 Qualcomm HTP 优化

**标签：** Runtime · NPU/GPU

**更新：** 11月23日正式发布。新增 HTP 初始化加速、加载阶段性能投票、内存预算及 DLBC 压缩控制；Android OpenCL 获得混合架构融合内核和长上下文 FlashAttention。官方报告混合 LLM 在 Android GPU 上生成速度最高提升18%，部分长上下文场景节约最高2.1GB RAM；新增 Windows ARM64 和 Linux aarch64 Qualcomm NPU 相关工具与支持。

**判断：** 值得优先复测 Qualcomm 模型的加载时间、内存与性能；18% 是 GPU 路线的官方结果，不代表 HTP 提速或所有手机都能复现。

**来源：** [LiteRT v2.4.0 Release](https://github.com/google-ai-edge/LiteRT/releases/tag/v2.4.0)

### LiteRT-LM v0.20.0：NPU 默认执行策略改变

**标签：** LLM Runtime · NPU

**更新：** 11月23日正式发布，增加 LlmNpuExecutorMetadata，从 .litertlm 包元数据读取未显式配置的 NPU 执行选项；部分手写 NPU 组件默认关闭，除非元数据或运行时参数明确启用（ring-buffer 模型的 KV cache 更新例外）。同时修正 benchmark 初始化计时的重复计算，并支持可复现的模型包构建；本版是最后支持 Python 3.10 的版本。

**判断：** 这是影响旧模型包兼容性与性能复测的重要更新。升级前应核对硬件 masking、cache update、PLE 等开关；初始化指标也不能直接与旧版 benchmark 比较。

**来源：** [LiteRT-LM v0.20.0 Release](https://github.com/google-ai-edge/LiteRT-LM/releases/tag/v0.20.0)

## AI 行业热点

### GLM-5.4：智谱首个旗舰 Loop Transformer

**标签：** Frontier Model · Architecture

**更新：** 智谱11月23日发布 GLM-5.4，在750B级 GLM-5 基座上让28层共享权重执行两轮，并联合优化推理内核和缓存；官方报告低峰最高200 tokens/s、高峰70–80 tokens/s，支持视觉及复杂工程编码。目前开放 Coding Plan、ZCode 和 Chat，普通 API 和开放权重尚待推出。

**判断：** 循环架构以额外计算换取更高有效深度，值得关注小模型迁移潜力，但不等于减少推理时延，也不是当前可部署到手机的模型。

**来源：** [智谱官方技术博客](https://z.ai/blog/glm-5.4)

### Upstage Solar Mini 4.5 Preview 开放 API

**标签：** MoE · Agent

**更新：** 官方文档确认11月23日开放预览版，35B总参数、3B激活参数、512K上下文、最高128K输出，支持英语、韩语、日语以及推理、工具调用和结构化输出；预览价格为每百万输入/输出 token 0.01/0.04 美元，正式版计划12月1日推出。

**判断：** 可作为低成本云端 Agent 候选，但3B激活参数不意味着只有3B权重，目前无公开手机部署包。

**来源：** [Upstage 官方模型文档](https://console.upstage.ai/docs/models/solar-mini-4-5-preview)
