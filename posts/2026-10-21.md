## 模型与多模态

### Spark-X2.6-4B 发布：面向手机 Agent 的新一代 4B 模型

标签：Small LLM；Agent / Tool Calling

**更新：** SparkLLM（XHToken）于 **10月21日凌晨（北京时间）**在 Hugging Face 发布 Spark-X2.6-4B 及 Base 权重，Apache-2.0、文本输入输出、约 4B 参数。沿用 X2.5 架构，主要改进后训练；官方宣称增强代码、工具调用、多语、长上下文与推理，支持 none/low/high 三档思考预算。模型卡提供 Transformers、SGLang、vLLM、MLX、llama.cpp、Ollama 路线，并演示服务器端最高 1,048,576-token 配置；该配置不代表手机可实际承载 1M 上下文，厂商性能图尚待独立复测。

**判断：** 这是今天最值得加入手机 Agent 替换候选的模型，可与 Qwen3.5-4B、Bonsai 2 4B 在中文指令、意图与参数抽取、工具调用成功率、长对话稳定性上对测。现有文档说明 GGUF/本地运行路径，但**没有 SM8750/SM8850 QNN/HTP full delegation、真机 prefill/decode/RAM/功耗的独立证据**；不要将「面向端侧」等同于 NPU 已适配。

**来源：** [Spark-X2.6-4B 官方模型卡](https://huggingface.co/XHToken/Spark-X2.6-4B) · [Base 权重](https://huggingface.co/XHToken/Spark-X2.6-4B-Base)。

## AI点评

1. **今天优先测 Spark-X2.6-4B 的中文工具调用。** 与 Needle3、Qwen3.5-4B 和 Bonsai 2 分别比较工具选择、槽位抽取、无效参数率及三档思考预算的延迟，不能只看厂商综合分数。
2. **Pocket TTS 的 1.9M 英语模型值得做极小模型实验。** 先验证可懂度与声音克隆质量，再判断能否用于 Android CPU；对中文端侧 TTS 暂不构成直接替换。
3. **LiteRT Torch v0.10.0 的价值在转换链路覆盖。** Qwen3-ASR/TTS 的打包、静态 KV 长度及 Gemma Audio Encoder 可先做导出回归，再测 GPU/NPU 的真实图覆盖。
4. **语音 Agent 越来越强调流水线而非单一模型。** Voxtral 3 将 context biasing、说话终点检测、打断、tool calling 和 TTS 串成实时系统，值得用现有 ASR→Needle3→TTS 原型复现指标。
5. **端侧与服务器推理不能混淆。** DeepInfer、EAGLE-4 的高性能结果来自服务器 GPU/NPU；手机部署仍须单独证明可运行、全图委托、速度与功耗。
