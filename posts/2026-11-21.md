## 模型与多模态

### Inkling 2 Mini：开放权重的循环 MoE 多模态 Agent 模型

**标签：** Open Weights · Agent

**更新：** Thinking Machines Lab 的官方模型卡标注 **2026年11月20日**发布 Inkling 2 Mini，Apache-2.0，支持图像+文本输入、文本输出和最高1M上下文。模型共 **26.4B 参数**，常规激活3.4B；中间12层循环运行三次后每token有效激活约5.4B。原生 NVFP4/MXFP8 混合精度权重约20GB；官方支持 NVIDIA DGX Spark、至少32GB内存的 Apple Silicon 及多种服务器推理框架。官方报告 MCP Atlas Public 82.7%、BrowseComp 79.0%，并展示离线 MacBook Pro 上的 Agent 编码演示；这些是厂商报告的测试结果，不是手机实测。

**判断：** 值得作为复杂搜索、工具调用与多模态 Agent 的**桌面/云端能力对照**，但不是0.1B–4B手机模型：有效激活规模不等于总权重占用，20GB checkpoint 和循环层执行都不适合直接替换 Needle3。官方未报告 Android QNN/HTP full delegation 或手机延迟、内存、功耗。

**来源：** https://thinkingmachines.ai/news/inkling-2-mini/ · https://huggingface.co/thinkingmachines/Inkling-2-Mini

## AI点评

1. **Inkling 的循环层架构值得研究，但先看真实内存和每token计算量。** 活跃参数小不意味着手机部署成本低，20GB权重是现实限制。
2. **TTS 候选可增加 ZONOS3-Mini。** 在普通话、英语和目标多语上与现有方案统一比较自然度、首音延迟、峰值内存及耗电。
3. **语音系统应评估事件级任务成功率。** 消防无线电案例提示：噪声、领域术语与响应时效可能比单独 WER 更接近产品价值。
4. **Agent 模型的 MCP/搜索分数需要任务级复现。** 用相同工具 Schema、检索语料与错误恢复机制比较，避免直接以厂商分数选型。
5. **继续将行业资本动态与端侧工程能力分开。** 大规模融资不能作为新模型性能、NPU 支持或产品落地的证据。
