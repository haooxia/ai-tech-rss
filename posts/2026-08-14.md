## 端侧框架与运行时

### LiteRT / LiteRT-LM

#### LiteRT v2.2.0 正式发布：GPU、QAIRT 与 NPU 路线同步升级

`LiteRT` `Release`

**更新：** LiteRT 于本统计窗口内正式发布 **v2.2.0**。GPU 侧加入 FP16 存储/计算 + FP32 累加精度模式、LLM ROPE composite op（官方称 decode 约提升 5%）以及更省初始化内存的权重重排；QAIRT accelerator 对齐 SDK 2.47，补充 SoC 名称/数值选择、QNN Native Path 文档和 A8W2 Fully Connected 等算子覆盖，同时新增 Intel NPU JIT/AOT、Rust binding、KV cache zero-copy 的 FeedbackLoopConfig 等能力。

**判断：** 这是今天对端侧部署最直接的一次正式版本升级。对 Snapdragon 路线尤其值得跟进的是 QAIRT 2.47 对齐和 QNN 侧工具链完善；对 Qwen/Gemma GPU 路线，ROPE、混合精度和模型初始化内存优化都可能直接影响真机 TTFT、峰值内存和稳定性。

**来源：** [LiteRT v2.2.0 Release](https://github.com/google-ai-edge/LiteRT/releases/tag/v2.2.0)

#### LiteRT-LM 补齐 Swift EmbeddingEngine API

`LiteRT-LM` `Embedding`

**更新：** LiteRT-LM 主线新增 Swift 的 Embedding Engine API，与既有 C、Kotlin 实现对齐；同一窗口还继续整理 LitertState 的 KV/state buffer 结构。

**判断：** 对 iOS/macOS 端侧检索、相册语义搜索和 RAG 原型更实用：EmbeddingEngine 不再主要停留在 C/Kotlin 路线，跨平台端侧 embedding 应用的 API 面进一步收齐。

**来源：** [LiteRT-LM Swift EmbeddingEngine commit](https://github.com/google-ai-edge/LiteRT-LM/commit/5c490382d7b2257bf39d31074f46561b6e1ac613)

### Qualcomm Genie / GenieX / QNN / HTP

#### GenieX v0.4.0 正式发布；QAIRT 模型选择与 HTP/MTP 路径集中修复

`GenieX` `Release`

**更新：** Qualcomm 在本窗口正式发布 **GenieX v0.4.0**，提供新的 Android AAR 与 Android/Linux/Windows arm64 工具包。同日主线修复 AI Hub 从 `RUNTIME_GENIE` 向 `RUNTIME_GENIEX_QAIRT` 迁移时的模型资产选择盲区，已在 Snapdragon X Elite 上验证 Gemma-4-E4B-it 的 W4A16 QAIRT 包可成功拉取并在 NPU 推理；另一个 MTP 修复将 Gemma-4-26B 在 X2 Elite 上的 prefill 从约 **217 tok/s 提升到 479 tok/s**，并补了 VLM 模型释放与 HTP session 生命周期问题。

**判断：** 这批变化不只是版本号更新，而是直接处理“模型能列出来却拉不下来”、HTP 映射泄漏、连续加载 session churn 和 MTP prefill 低效等部署问题。对 GenieX + QAIRT/llama.cpp 混合使用场景，v0.4.0 值得优先回归测试。

**来源：** [GenieX v0.4.0 Release](https://github.com/qualcomm/GenieX/releases/tag/v0.4.0)；[QAIRT runtime selector fix](https://github.com/qualcomm/GenieX/commit/bd08af8aff97d0cf609fe82a49ea67930e11dcfa)；[MTP prefill fix](https://github.com/qualcomm/GenieX/commit/8773df79ed6d4ceaa6f2eacb08fc542e038a5955)

### MNN

#### Hexagon 新增 Int4 VRMPY decode GEMV，并继续优化 FlashAttention/GEMM

`MNN` `Hexagon`

**更新：** MNN 主线为 Hexagon 后端加入 **Int4 VRMPY decode GEMV（M=1）**，同时优化 FlashAttention 与 GEMM；这是面向 LLM decode 核心路径的直接性能提交。

**判断：** 对 Snapdragon 端侧 LLM 很有价值：M=1 GEMV 正是逐 token decode 的典型形态，Int4 + VRMPY 若在目标 Hexagon 版本上覆盖稳定，有机会继续拉开 MNN NPU/Hexagon 路线与 CPU/GPU 的 decode 差距，值得在 SM8750/SM8850 类设备上做真机回归。

**来源：** [MNN Hexagon Int4 VRMPY commit](https://github.com/alibaba/MNN/commit/af19bb571ea089d2f6f56fd79a6347c8a243b7df)

#### MNN 增加 Qwen3.5 视频输入支持

`MNN` `Qwen3.5`

**更新：** MNN LLM 模块合入 Qwen3.5 video input 支持，将 Qwen3.5 的多模态输入范围从图像进一步扩展到视频路径。

**判断：** 这是端侧 Qwen3.5 VLM 能力面的实质扩展，但是否适合手机端仍取决于视觉编码、帧采样与峰值内存；短期更适合作为功能可用性信号，后续要看 Android demo、量化与后端加速数据。

**来源：** [MNN Qwen3.5 video input commit](https://github.com/alibaba/MNN/commit/d68305cf2476a7dc319643ba7c62f44e2bc5246b)

## 模型与多模态

### 小模型 / 手机可部署模型

#### Qwen3.5-4B 首次进入 LiteRT-LM 社区模型：4.10 GB Int8，iPhone 已有实测

`Qwen3.5` `LiteRT-LM`

**更新：** LiteRT Community 在本窗口发布 `Qwen3.5-4B` 的 `.litertlm` 转换，要求 LiteRT-LM ≥0.15；当前包为文本 decoder，Int8 文件约 **4.10 GB**。模型卡给出的 iPhone 17 Pro 实测为 GPU prefill **87.1 tok/s**、decode **9.3 tok/s**、峰值约 **4.98 GB**；CPU decode **5.4 tok/s**、峰值约 **1.70 GB**。

**判断：** 这是 Qwen3.5 4B 进入现成 LiteRT-LM 部署生态的重要一步，但模型卡明确提示 8 GB 级 Android 不适合当前包，Android 更现实的门槛是 12 GB+。它属于“已有运行时适配、但手机适用性受内存约束”，不是普通意义上的轻量手机模型。

**来源：** [litert-community/Qwen3.5-4B](https://huggingface.co/litert-community/Qwen3.5-4B)

#### Falcon-H1 0.5B/1.5B 与 Nemotron-H 4B 同日新增 LiteRT-LM 转换

`Small LLM` `LiteRT-LM`

**更新：** LiteRT Community Activity 在本窗口显示新发布 `Falcon-H1-0.5B-Instruct`、`Falcon-H1-1.5B-Instruct` 与 `Nemotron-H-4B-Instruct-128K`。其中 Falcon-H1 0.5B Int8 约 **650 MB**，Pixel 8a OpenCL 已验证完整 delegate，实测 decode **11.8 tok/s**；1.5B Int8 约 **1.61 GB**；Nemotron-H 4B Int8 约 **4.67 GB**，模型卡明确指出 8 GB Android 仍不够。

**判断：** 这批模型比单纯“新 checkpoint”更值得关注，因为已经带 `.litertlm`、量化与真机数据。尤其 Falcon-H1 0.5B 是今天更像真正手机级候选的一款；Nemotron-H 4B 则更接近高内存设备/Apple 端优先路线。

**来源：** [LiteRT Community Activity](https://huggingface.co/organizations/litert-community/activity/all)；[Falcon-H1-0.5B-Instruct](https://huggingface.co/litert-community/Falcon-H1-0.5B-Instruct)；[Falcon-H1-1.5B-Instruct](https://huggingface.co/litert-community/Falcon-H1-1.5B-Instruct)；[Nemotron-H-4B-Instruct-128K](https://huggingface.co/litert-community/Nemotron-H-4B-Instruct-128K)
