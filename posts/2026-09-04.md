## 模型与多模态

### IFM 发布 K2 Horizon：0.9B / 3.7B / 7B 直接面向端侧与手机
`Small LLM` `On-device`

**更新：** Institute of Foundation Models（IFM）正式发布 K2 Horizon 六模型家族：0.9B、3.7B、7B、32B、36B-A4B 与 375B-A23B，并公开最终权重、训练代码、数据/数据构造配方、中间 checkpoint、训练日志与评测，模型和代码采用 Apache-2.0。官方明确把 0.9B 定位到手表/眼镜等受限设备，把 3.7B / 7B 定位到手机与其他 on-device 场景；0.9B 支持 128K context，官方表中 AIME 2026 为 48.5、HumanEval+ 为 79.9、LiveCodeBench v6 为 37.4。

**判断：** 这是今天对端侧业务最值得关注的新模型家族之一。0.9B 尤其值得与 Qwen3.5-0.8B、Spark-X2.5-1.7B 做中文/Agent/端侧性能对照；但当前公开部署路径主要是 Transformers、vLLM、SGLang 与通用量化，尚未看到 LiteRT / MNN / QNN / GenieX 或 Snapdragon 手机 NPU 真机 benchmark，因此“可在手机运行”与“已适配手机 NPU”必须分开。

**来源：** [IFM / K2 Horizon 官方发布](https://ifm.ai/blog/k2/) · [K2-Horizon-0.9B](https://huggingface.co/IFM/K2-Horizon-0.9B)

`Frontier Model` `Agent`

**更新：** 9 月 2 日简报已报道 Astra 的发布前预告；9 月 3 日 OpenAI 正式开始发布 GPT-6 Astra。官方模型页给出 **1,050,000 context window、128K max output**，支持 function calling、web search、computer use、MCP、Skills 等工具，API 标价为 **$10/M input、$50/M output**。Astra 同时成为 OpenAI 首个达到 Preparedness Framework **Critical cybersecurity capability** 的广泛部署模型，当前先向 Trusted Access 企业开放，并将在随后几天扩展到 API 与 Plus / Pro / Business / Enterprise。

**来源：** [OpenAI / GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra) · [Safety overview](https://openai.com/index/safety-overview-gpt-6-astra/)

**更新：** NVIDIA 宣布已达成协议，以 **$12.93B** 收购 Hugging Face。NVIDIA 表示 Hugging Face 将继续作为开放平台运行，开发者仍可选择任意模型、框架、云、推理服务商与计算平台，并明确表示使用 Hugging Face 不要求采用 NVIDIA compute。

## AI点评

1. **K2 Horizon 0.9B 很值得马上加入端侧小模型对照组。** 它不是只强调“能跑”，而是在 0.9B 规模同时给出 reasoning、coding、tool-use 能力；最有价值的下一步是测中文、指令跟随、真实手机 RAM / tok/s 和量化后退化。
2. **K2 Horizon 的“完全开放训练链路”本身很有价值。** 对端侧团队来说，这意味着不只拿最终权重，还可以研究其 distillation、agentic post-training 和中间 checkpoint，后续做更小模型蒸馏或任务定向微调会更方便。
3. **Astra 正式 rollout 后，Agent 评测标准要继续从单轮质量转向端到端任务。** 1M context、computer use、MCP/Skills 与长程工具调用一起出现后，tool calls、累计 tokens、重复 prefill、任务完成时间和安全边界都会变成更重要指标。
4. **NVIDIA 收购 Hugging Face 需要持续观察对多硬件生态的影响。** NVIDIA 已公开承诺保持平台开放，但对移动端而言，Qualcomm / MediaTek / Apple / LiteRT / MNN 等非 CUDA 路径是否继续得到同等资源与曝光，会比口头承诺更重要。
