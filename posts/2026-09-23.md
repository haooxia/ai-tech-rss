### Claude Opus 5.5 正式发布：Fable 级能力下放，Agent 成本显著下降
`Frontier Model` `Agentic Coding`

**更新：** Anthropic 于 9 月 22 日发布 Claude Opus 5.5，是 Claude 5.5 家族首款模型。官方称其在多数任务上达到 Fable 5.1 水平，较 Opus 5 典型任务成本降低约 40%、输出速度提升 30% 以上；API 定价降至 $4/M input、$20/M output，cache read 降至 $0.20/M。官方评测给出 Terminal-Bench 4.0 66.4%、FrontierCode v1.1 54.4%、CursorBench 4.0 57.8%，并同步进入 Claude Platform、AWS、Google Cloud、Azure 与 GitHub Copilot。

**判断：** 这次最值得关注的不是单纯 benchmark 第一，而是“更少 token / 更少 agent steps + 更低 cache 成本”。对长程 Coding/Agent 工作负载，实际每任务成本可能比单看 token 单价更重要；但这些 benchmark 仍以官方/早期合作方数据为主，后续要看独立评测。

**来源：** [Anthropic / Claude Opus 5.5](https://www.anthropic.com/claude-opus-5-5) · [GitHub / Opus 5.5 in Copilot](https://github.blog/changelog/2026-09-22-claude-opus-5-5-is-now-available-in-github-copilot/)

### OpenAI 发布 GPT-6 Sol / Luna：Astra 能力下沉，API 价格明显降低
`Frontier Model` `Efficiency`

**更新：** OpenAI 于 9 月 22 日扩展 GPT-6 家族，正式发布 GPT-6 Sol 与 GPT-6 Luna。两者均支持文本/图像输入；标准 API 定价分别为 Sol $2/M input、$10/M output，Luna $0.10/M input、$0.50/M output，cached input 分别低至 $0.20/M 与 $0.01/M。OpenAI 称两款模型继承 Astra 的专业工作、coding、computer use 与 alignment 改进，并通过更高效 caching / inference 将价格较 GPT-5.6 对应档位明显压低。

**判断：** 这与 Opus 5.5 同日发布形成很强的“能力不只涨 benchmark，而是压每任务成本”信号。Sol 更值得用于复杂 Agent/Coding 对照，Luna 则值得关注高并发 routing、轻任务和成本敏感型 Agent 子任务；二者都不是端侧模型。

**来源：** [OpenAI API Changelog](https://developers.openai.com/api/docs/changelog) · [OpenAI / GPT-6 Astra 页面更新](https://openai.com/index/gpt-6-astra/)

## AI点评

1. **今天最明显的行业信号是 frontier model 开始竞争“每个完成任务的总成本”，而不仅是 token 单价。** Opus 5.5 强调更少 steps/tokens，GPT-6 Sol/Luna 强调 caching 与 inference efficiency；Agent 评测以后应同时记录成功率、总 tokens、tool calls、wall time 和总成本。
2. **Opus 5.5 很值得纳入真实 Coding Agent 对照。** 官方数据里它在长程 coding 和 token efficiency 上提升明显，但需要用自己的 repo/task 测“完成质量 ÷ 总成本”，而不是只看 Terminal-Bench。
3. **Jev 的“两层 Agent”模式正在从概念变成产品集成。** 对端侧 Agent 也有启发：不一定所有动作选择都交给 1B–3B 通用模型，可以让 tiny router / decision model 承担高频结构化决策，再把复杂任务升级给大模型。
4. **端侧今天依旧没有必要硬凑新闻。** 没有新的 Runtime release 或手机 NPU 实证时，坚持区分“可编译 → 可运行 → full delegation → 实际更快”比追仓库更新时间更有价值。
