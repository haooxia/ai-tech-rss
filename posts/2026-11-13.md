### ExecuTorch v1.6.0：Qualcomm 多芯片 Context Binary 与 HTP Profiling

**标签：** ExecuTorch · QNN

**更新：** PyTorch 于 **11月13日01:01（北京时间；11月12日17:01 UTC）**发布 **ExecuTorch v1.6.0**。Qualcomm 后端升级至 **QNN SDK 2.51**，增加**跨多个 Snapdragon SoC 的 Flexible Context Binary 导出**、端侧 OpTrace 与 host-only Hextimate HTP profiling、用于加快 context finalization 的 HTP graph-splitting 选项、Hugging Face LLM 的 **8-bit KV-cache I/O**、LLM QAT 的 W4 embedding/LM-head 量化，以及 SC8480XP、Snapdragon 7+ Gen 3 支持和设备端 AdamW。Vulkan 后端新增动态 Transformer block 完整委托、fused SwiGLU 及 Mali/Adreno 内核优化；CUDA/MLX 增加 batching、prefix cache 与 DFlash；NXP Neutron 达到 production-ready。

**判断：** 对手机端 LLM 最有替换价值的是 **跨 SoC 编译包、HTP 分图/分析、8-bit KV cache 和 W4 量化**。建议将其列入 SM8750/SM8845 的 QNN/LiteRT/GenieX 横向评估；不过“Flexible Context Binary”不保证所有 SoC 都能使用同一文件，HTP graph-splitting 也不代表整个模型 full delegation，仍需核实支持矩阵、fallback、编译/加载时间与同条件实测。

**来源：** https://github.com/pytorch/executorch/releases/tag/v1.6.0
