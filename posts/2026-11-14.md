**标签：** Runtime · API Compatibility

**更新：** ggml-org 于**11月13日**正式发布 llama.cpp 与 ggml 两个库的 **v1.0.0**。这次的核心是清理历史 API、明确语义化版本规范：公共 C API 的破坏性变化升主版本，兼容性新能力/后端/模型支持升次版本，纯修复升补丁版本；项目也明确了 Android/iOS 等预发布二进制工件和 iOS/macOS XCFramework 分发路径。**并没有宣称 v1.0.0 本身带来新的手机 NPU 全委托或显著速度提升。**

## AI 行业热点

### OpenAI ChatGPT Wallet：Agent 可在逐笔授权后完成真实支付

**标签：** Agentic Commerce · Tool Execution

**更新：** OpenAI 于**11月13日**推出 **ChatGPT Wallet**，开始在美国向符合条件的成年 ChatGPT Pro 用户通过 dots 逐步开放。用户先添加合格的美国发行银行卡，Agent 购物时需由用户审阅商品、金额和支付卡，并通过 Face ID/指纹等方式**逐笔确认**；支付网络提供 token，Agent 与商家不获取用户真实卡号。OpenAI 同时发布商家接入指导，涵盖 Web Bot Auth、风控识别、商品信息和插件/WebMCP 工具；未来预授权支付仍是规划，**当前不是无限制自动扣款**。

**判断：** Agent 正从“搜索、比较、生成建议”走向**真实世界交易执行**。对 SeekPilot 的可借鉴点是将工具路由、执行前权限检查、用户确认、操作记录与失败恢复分层设计；此发布不涉及手机本地模型、HTP 或 NPU。

**来源：** https://openai.com/index/introducing-chatgpt-wallet/

### AllenAI XYBench：8,115 道题评测 AI 能否识别用户真正想解决的问题

**标签：** Agent Evaluation · Intent Understanding

**更新：** Allen Institute for AI 于**11月13日**发布 XYBench 技术介绍及 8,115 条评测题，测试助手面对用户错误假设时，能否从字面请求 Y 找到真正目标 X，并据此调整回答重点。数据覆盖编程和生活任务；研究报告在 Stack Overflow 子集上，所测模型只有 **35%–41%** 的回答把重点放在真正目标上。论文和资源有此前研究背景，**本期新增的是11月13日公开的基准介绍/资源发布信息**，不将其误写为全新模型。

**判断：** 对本地搜索 Agent 很有参考价值：用户说“帮我找某个文件”可能真正需要“定位一项信息并执行后续操作”。可以在 SeekPilot 测试集中加入**字面请求与真实意图不一致**的 case，分别测意图识别、工具选择和最终任务成功率；现有 XYBench 主要是英语，不能直接代表中文表现。

**来源：** https://huggingface.co/blog/allenai/xybench · https://huggingface.co/datasets/allenai/XYBench-dataset

## AI点评

1. **Agent 工程的安全边界比单纯工具调用准确率更重要。** Wallet 的逐笔授权、支付 token、审计记录提供了高风险工具执行的产品参考；端侧助手也应明确哪些动作必须经过用户确认。
