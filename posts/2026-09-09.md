## AI 行业热点

### Meta 正式推出 Muse：个人 Agent 进入“持续后台执行 + 跨应用操作”阶段
`Personal Agent` `Agent Runtime`

**更新：** Meta 9 月 8 日在美国上线 Muse，可通过独立 App、WhatsApp 与 Web 使用。Muse 运行在独立 Muse Secure VM 中，可调用浏览器、跨应用执行邮件、旅行预订、表单填写、谈判和支付等任务，并可在用户关闭 App 后继续工作；敏感动作前请求确认，同时由与主 Agent 系统级隔离的 Sentinel agent 检查外部连接，提供完整动作审计记录。

**判断：** 这比“又一个聊天助手”更重要：大型消费级 Agent 正把 VM 隔离、凭据托管、动作审计、敏感操作确认和 prompt-injection 防护变成产品基础设施；对未来手机 Agent / AI OS 的架构参考价值很高。

**来源：** [Meta / Introducing Muse](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)

`AI for Science` `Multi-Agent`

**更新：** OpenAI 9 月 8 日发布一套由内部系统生成的 Navier–Stokes Millennium Prize Problem 解法，包含分析证明与 Lean formalization；官方称产生核心结果的内部模型“显著强于 GPT-6 Astra”，约 10,000 个并发 agents 参与 Navier–Stokes 阶段，产生约 1300 亿 output tokens，最终 Lean formalization / verification 再由 GPT-6 Astra 完成。OpenAI 将其描述为证明有限时间 singularity 的解法，但该结果仍需数学界独立审查，不能等同于 Clay Mathematics Institute 已正式接受。

## AI点评

1. **LiteRT-LM v0.17.0 的 Local Attention 优化比表面上的版本号更值得关注。** 手机 LLM 的 context 经常先被 KV cache / RAM 卡住；后续应优先测同一模型在 v0.16.x 与 v0.17.0 下的峰值 RAM、长 prompt TTFT 和可稳定 context，而不只测 decode tok/s。
2. **端侧算力正在重新变成“异构系统问题”。** Arm 今天同时强化 CPU SME2、GPU neural acceleration 和模型/runtime 分发，说明 CPU/GPU 并不会因为 NPU 存在就退出 AI 主路径；具体任务仍要看 kernel、量化和数据搬运成本决定放在哪个引擎。
3. **Qwen3-TTS 在 vivo X300 上的 >4× CPU 加速值得单独记入后续 TTS 评测池。** 它没有证明 NPU 更强，但说明对语音模型而言，CPU SME2 + mixed quantization 可能已经足以形成很有竞争力的手机实时路径。
4. **Muse 把 Agent 安全从“模型拒答”推进到 runtime 安全架构。** 独立 VM、凭据不可见、Sentinel、动作审计、敏感动作确认这些机制，比单纯提高模型 alignment 更接近可落地的手机 Agent / AI OS 设计。
5. **OpenAI 的科研结果把 Agent scaling 推到了一个新量级。** 万级并行 agents 和百亿级以上 token 消耗说明前沿科研 Agent 的核心变量已不只是单模型能力，还包括任务分解、并行探索、交叉汇总和形式化验证；后续更值得看这种方法能否在更低计算预算下复现。
