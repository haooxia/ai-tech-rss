## AI点评

1. **优先验证 GenieX Decisions API。** 比较 Jev-shaped 接口、OpenAI Decisions API 与传统 LLM 生成 JSON 在中文意图路由上的准确率、尾延迟、内存和误触发率，尤其关注是否需要逐 token 生成。
2. **区分“HTP mapping 移出 TTFT”和真实启动提速。** 预热可以改善请求首 token 指标，但必须同时测量冷加载、首次请求和连续请求的总耗时。
3. **端云混合 Agent 的分工越来越具体。** Google 的端侧链接判定与云端复杂对话识别值得借鉴；需要同步设计用户授权、敏感上下文边界和云端降级策略。
4. **MoE 手机化仍受总权重约束。** LFM2.5-24B-A2B 的活跃参数较少，但实际是否适合手机取决于专家存储、带宽、量化、缓存和真机功耗，不能直接按“2B”归类。
