## AI点评

1. **今天最值得关注的不是 frontier model，而是“LLM 外围决策层”开始分化。** Jev 把决策/概率从聊天模型里拆出来，Needle 3 把 tool routing/参数抽取压到几十 MB；两者都在挑战“每一步都调用通用 LLM”的 Agent 架构。
2. **Needle 3 很适合做一次中文 Android API / DroidCall 定向微调实验。** 它已经提供 LoRA fine-tuning + export，且 29M 级子网络足够小；真正应该测的是中文 paraphrase、否定、多个连续 tool call、out-of-scope refusal 和相似 tool 混淆，而不是只跑英文官方 demo。
3. **Needle 3 当前的优势不是 NPU。** 官方 runtime 重点是极小 CPU engine 与 2-bit 权重，模型小到 CPU 就能非常快；这提示端侧系统设计里“把模型做到足够小”有时比强行追求 NPU delegation 更实用。
4. **Jev 的下一道证据门槛是独立评测。** 官方 193.6× / 444.6× 数字很吸睛，但在独立 workflow benchmark、校准误差和 failure mode 出来前，不应把它视为已经证明优于 LLM 的通用决策替代品。
